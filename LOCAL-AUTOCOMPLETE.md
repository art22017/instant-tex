# Локальное автодополнение — Windows

Кнопка **Autocomplete** в верхней панели открывает настройки. Выбери Intel CPU,
Intel Arc GPU или Intel NPU и нажми **Включить**. **Остановить** завершает процесс
модели и освобождает её память. Для смены устройства сначала останови модель.
Запуск не делает пробную генерацию. При закрытии приложения раннер останавливается.

Подсказка появляется серым после паузы в наборе. **Tab** вставляет её в документ,
**Esc** скрывает, **Alt + \** запрашивает вручную. Подсказка до принятия не попадает
в документ, сохранение или предпросмотр. Обычный список команд LaTeX имеет приоритет.
Максимальная длина настраивается от 8 до 128 токенов; по умолчанию 32.

Настройка **Подсказки внутри строки** разрешает вставку перед уже набранным текстом:
серое продолжение плавно раздвигает правую часть строки. До принятия по Tab документ
остаётся прежним; Esc убирает подсказку. По умолчанию настройка выключена и подсказки
показываются в конце строки. Выбор сохраняется между запусками.

В Linux и macOS кнопка скрыта. Установщик содержит только интерфейс и небольшой
адаптер, **без весов, llama.cpp, Python, OpenVINO и кеша компиляции**. Приложение
не скачивает их автоматически. Нет зависимости от демки на порту 5174.

## Файлы пользователя

Папка: `%APPDATA%\InstantTeX\autocomplete` (рядом с остальными настройками).
Её можно открыть из окна Autocomplete. Ожидаемая структура:

```text
autocomplete/
  settings.json             # создаётся приложением: device, maxTokens
  qwen-base-q4_k_m.gguf      # Qwen2.5-Coder 1.5B Base, GGUF Q4_K_M
  llama/                    # официальный Windows x64 Vulkan build llama.cpp
    llama-server.exe
    *.dll                   # включая llama-server-impl.dll и Vulkan backend
  ov-int4/                  # экспортированный OpenVINO INT4 Qwen Base
    openvino_model.xml
    openvino_model.bin
    openvino_tokenizer.xml
    openvino_tokenizer.bin
    openvino_detokenizer.xml
    openvino_detokenizer.bin
    ...                     # остальные config/tokenizer файлы экспорта
  python/                   # пользовательское окружение Python для NPU
    Scripts/python.exe
    Lib/site-packages/      # openvino, openvino_genai, openvino_tokenizers, numpy
    pyvenv.cfg
  npu-cache/                # кеш OpenVINO; пересоздаётся при необходимости
  logs/                     # журнал запуска выбранного устройства
```

Python и его окружение должны работать на данном компьютере. Перенос Windows venv
между компьютерами не поддерживается; при ручной установке создай окружение в этой
папке и установи совместимые пакеты OpenVINO GenAI. Для проверенной здесь модели
использован OpenVINO GenAI 2026.4.0, Intel NPU driver 32.0.100.5540.

CPU/GPU запускаются отдельным процессом llama.cpp только на `127.0.0.1`, со случайным
портом и ключом для каждого запуска. NPU запускается отдельным Python-процессом с
OpenVINO GenAI на явно выбранном устройстве `NPU`; HTTP-адаптер также слушает только
loopback и проверяет ключ. Текст передаётся из редактора через Electron IPC.

Контекст ограничен ближайшими 5000 символами перед курсором и 1500 после него.
NPU дополнительно сокращает контекст около курсора до окна 1000 токенов.
Сохранённый дисковый кеш NPU используется при запуске; смена драйвера или версии
OpenVINO может потребовать его пересоздания. Документы и подсказки в журналы не пишутся.

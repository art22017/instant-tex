Коротко о редакторе

Русский текст — как есть. Формулы: \(…\), \[…\], $…$, $$…$$. Есть gather, align, матрицы и системы.

Ctrl+Space — команды. Tab — принять / следующая скобка. Enter внутри многострочной формулы добавляет \\; Shift+Enter — только перенос.

Ctrl + колесо меняет масштаб только панели под курсором. Шестерёнка сверху задаёт размер шрифта кода и превью. Настройки запоминаются.

Частота выбора сортирует команды. Команды из документа появляются сразу и после минуты без ошибок попадают в общий словарь.

Выдели код или текст превью → Ask AI. Кнопка внизу справа задаёт вопрос по всему документу. Передаются context, selection, question. Ответ не меняет текст.

Превью использует KaTeX, не весь TeX. Пакеты из преамбулы не выполняются. PDF — печать превью. Черновик в памяти; Ctrl+S сохраняет его.

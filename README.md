# Instant TeX

Локальный черновик для математических решений: пиши русским текстом и LaTeX, а результат сразу смотри рядом с кодом. Приложение не запускает полноценный TeX-компилятор: текст и формулы отображаются локально через KaTeX, без установки TeX Live или MiKTeX.

## Скачать

Готовые сборки появляются на странице [Releases](https://github.com/art22017/instant-tex/releases):

- **Windows x64:** пользовательский установщик `Setup.exe`; после установки приложение запускается напрямую.
- **Linux x64:** AppImage.
- **macOS Apple Silicon:** `.dmg` и `.zip` для arm64.

Сборки не подписаны сертификатами издателя. Windows или macOS могут показать предупреждение при первом запуске.

## Возможности

- Редактор CodeMirror 6 с автодополнением LaTeX, парными скобками, умным вводом окружений, undo/redo и общим словарём команд.
- В Windows — необязательные локальные серые FIM-подсказки от Qwen2.5-Coder 1.5B Base на Intel CPU, Arc GPU или NPU.
- Мгновенный предпросмотр русского текста и математических формул на KaTeX, включая `\boxed`, `gather`, `align`, матрицы и другие поддерживаемые KaTeX команды.
- Шаблон нового решения с русской преамбулой и секциями «Задача», «Решение», «Ответ».
- JetBrains Mono для редактора и интерфейса, CMU/Computer Modern для превью. Размеры и вес шрифта редактора настраиваются отдельно; `Ctrl` + колесо меняет масштаб панели под курсором.
- Светлая и тёмная темы.
- Изображения PNG/JPEG/WebP/GIF из буфера, перетаскиванием или через кнопку на панели; таблицы, списки, подписи, нумерация и библиография.
- Явные команды открыть/сохранить `.tex`/`.txt`/`.itex`; экспорт текущего превью в PDF, PNG или буфер обмена.
- Необязательный AI-чат через OpenRouter с потоковым ответом, историей, Markdown и LaTeX.
- Режим Work на [Pi SDK](https://github.com/earendil-works/pi/tree/main/packages/coding-agent): агент читает черновик, ищет фрагменты, проверяет KaTeX и предлагает изменения с диффами и подтверждением.

Черновик редактируется в памяти. Автосохранения исходника нет: сохрани текст явно, если хочешь оставить его после закрытия. PDF — экспорт предпросмотра Chromium, а не результат pdfLaTeX или XeLaTeX. Полный LaTeX-проект, произвольные пакеты, TikZ/PGFPlots, произвольные стили BibLaTeX и макросы из пользовательской преамбулы не компилируются.

## Локальное автодополнение — Windows

Кнопка **Autocomplete** в верхней панели: выбор Intel CPU / Intel Arc GPU / Intel NPU,
**Включить**, **Остановить**, максимальная длина от 8 до 128 токенов. Пока модель работает,
смена устройства заблокирована. **Tab** принимает серую подсказку, **Esc** скрывает,
**Alt + \** запрашивает вручную. Подсказки внутри строки можно включить в настройках.
Текст обрабатывается локально, ключ OpenRouter не нужен.

Модель, llama.cpp, Python/OpenVINO и кеш устанавливаются пользователем отдельно в
`%APPDATA%\InstantTeX\autocomplete` и **не входят в установщик**. В Linux и macOS
кнопка скрыта. Структура файлов и запуск описаны в [LOCAL-AUTOCOMPLETE.md](LOCAL-AUTOCOMPLETE.md).

## AI и ключ

AI-чат выключен, пока пользователь сам не добавит ключ OpenRouter в настройках AI. Запрос уходит в OpenRouter из основного процесса приложения; текст документа, выделение и вопрос отправляются только при явном запросе AI. Остальные части приложения работают офлайн.

Ключ не хранится в исходниках, GitHub Actions, аргументах сборки или файлах релиза. На Windows он шифруется DPAPI для текущего пользователя в `%APPDATA%/InstantTeX`; на macOS/Linux используется Electron `safeStorage`. В workflow нет секрета OpenRouter и он не нужен для сборки или публикации приложения.

В каждом чате есть вкладки **Ask** и **Work**. Ask отвечает на вопросы. Work запускает сессию Pi в памяти с четырьмя инструментами: `read_document`, `search_document`, `check_latex`, `edit_document`. Текст, доступные события thinking и инструменты отображаются в хронологической ленте. Инструменты раскрывают аргументы и результат, активный этап имеет анимированный индикатор. Агент сразу редактирует рабочую копию, продолжает работу и проверяет изменённый текст без промежуточных подтверждений. Общий дифф нарастает в редакторе. Только после полного завершения появляются итоговые +/− и кнопки принятия/отклонения всего результата. При остановке или отключении Work неподтверждённые изменения откатываются. Принятый результат можно отменить одним Undo. На время редактирования агентом и проверки итогового диффа ручной ввод блокируется.

Work отключён по умолчанию. Открой шестерёнку → **Work…**, вручную введи показанную фразу и включи режим. Копирование текста настроек и вставка фразы отключены в интерфейсе. Выключение выполняется одной кнопкой и сохраняется между запусками. История хранит ответы и краткие сведения об инструментах; сессии агента и снимки диффов на диск не записываются. Work использует тот же локально сохранённый ключ и выбранную в поле вопроса модель OpenRouter.

Новые сообщения появляются снизу, чат следует за потоковым ответом. Ручная прокрутка вверх позволяет читать историю без скачков. Отправка вопроса, открытие чата и выбор его из истории возвращают к последним сообщениям. После завершения thinking и промежуточные события сворачиваются в раскрываемый блок, итоговый ответ остаётся видимым.

## Разработка

Нужен Node.js 22.19 или новее.

```sh
npm ci
npm start
npm test
npm run build
```

`npm run dev` запускает только UI в браузере. `npm run dev:desktop` открывает Electron с исходниками через Vite и горячим обновлением UI, без сборки приложения или установщика; диалоги сохранения и экспорта работают. Windows NSIS-установщик из локальной среды создаётся командой `npm run package`.

## Релизы

Опубликуй версионный Git-тег, совпадающий с `package.json` (сейчас `v0.9.1`). GitHub Actions проверит версию, выполнит unit-тесты и соберёт приложение на GitHub runners для Windows x64, Ubuntu x64 и macOS Apple Silicon arm64. Успешный запуск создаст GitHub Release с Windows NSIS Setup, Linux AppImage и macOS DMG/ZIP. Для сборки не требуются Actions secrets.

Технологии: Electron, CodeMirror 6, KaTeX, JetBrains Mono Variable, Computer Modern, Lucide.

## Модели AI

Селектор в нижнем правом углу поля вопроса общий для Ask и Work. Выбор сохраняется локально между запусками. Доступны DeepSeek V4.1 Flash, DeepSeek V4 Pro (0423), Gemini 3.5 Flash Lite и Gemma 4 31B без суффикса `:free` — BYOK настраивается в аккаунте OpenRouter.

Бесплатные варианты: `qwen/qwen3.8-27b:free`, `nvidia/nemotron-3.5-lightning:free`, `thinkingmachines/inkling-small:free`, `thinkingmachines/inkling:free`, `nvidia/nemotron-3-ultra-550b-a55b:free`, `nvidia/nemotron-3-super-120b-a12b:free`. Приложение передаёт эти ID без изменений и не заменяет их платными моделями.

[`openrouter/free`](https://openrouter.ai/docs/guides/routing/routers/free-router) автоматически выбирает бесплатную модель, поддерживающую нужные возможности, включая инструменты в Work. Это ID модели для обычного `/api/v1/chat/completions`, а не отдельный HTTP-эндпоинт. Доступность и ограничения моделей определяет OpenRouter.

## Лабораторные работы

Рабочий пример — [examples/lab.tex](examples/lab.tex), изображение находится рядом. Открой `.tex` в приложении: локальные изображения и `.bib`, указанные в документе, подхватываются из его папки. Файлы вне этой папки автоматически не читаются.

- **Изображения:** кнопка с картинкой на панели, вставка из буфера в редактор или перетаскивание PNG/JPEG/WebP/GIF. Добавляется `figure` с `\includegraphics`, `\caption` и `\label`. Размер: `width=0.8\linewidth`, `width=\textwidth` или `width=8cm`. Растровые графики вставляются так же, как изображения.
- **Таблицы:** `table` с подписью и `tabular`. Столбцы `l`, `c`, `r`, `p{4cm}`, `m{4cm}`, `b{4cm}`, повторение `*{2}{c}`, строки через `\\`, ячейки через `&`. Поддержаны `\hline`, `\cline`, линии booktabs и `\multicolumn`.
- **Списки:** `enumerate`, `itemize`, `description`, `\item` и вложенные списки. Нумерация обычного списка автоматическая; вложенные уровни отображаются буквами и римскими числами.
- **Номера и ссылки:** формулы по умолчанию отображаются без номера. Укажи номер вручную через `\tag{A}` в `equation`, `align`, `gather` или `multline`; `\label` рядом с тегом, `\ref` и `\eqref` поддерживают ссылки вперёд. `\notag`/`\nonumber` убирают номер строки. Подписи рисунков и таблиц и нумерация списков формируются автоматически.
- **Источники:** `thebibliography` / `\bibitem{key}` / `\cite{key}` либо импорт `.bib` той же кнопкой. Импорт добавляет `\bibliography{refs}`. Простой числовой список использует поля author, title, journal/booktitle/publisher, year, DOI/URL; `\cite{a,b}` ссылается на несколько источников. Это локальный разбор BibTeX, без Biber, сложных макросов, `.bst` и BibLaTeX-стилей. `\bibliographystyle` принимается для совместимости, но не меняет стиль превью.

С изображениями и `.bib` удобнее сохранять **`.itex`**: один файл с исходником и вложениями. При сохранении в **`.tex`** ресурсы записываются рядом, сохраняй всю папку вместе. В редакторе остаются только имена ресурсов, не base64. Лимит одного вложения — 16 МБ, общий — 64 МБ.

Преобразование изображений в строки для PDF выполняется только при экспорте. Во время набора используются Blob URL, кэш HTML-блоков и отдельный кэш KaTeX; неизменённые изображения не декодируются и не перерисовываются заново на каждый символ. Вложенные структуры ограничены 20 уровнями. Фигуры остаются на месте в тексте: LaTeX-алгоритм плавающих объектов не запускается.

## Изменения файла извне

После открытия или сохранения `.tex`, `.itex` или текстового файла приложение автоматически следит за ним. Пока файл не меняется, нет опроса, перечитывания и сообщений редактору: используется один нативный watcher папки с фильтром имени. Замена файла через временный файл и rename также отслеживается. Черновик и превью продолжают работать из памяти.

Внешние изменения объединяются с несохранённым текстом относительно последней общей версии. Независимые правки и дописанные строки сохраняются. При пересечении появляется «Сравнить»: для каждого фрагмента можно оставить текст редактора, вариант с диска или оба. Вложения тоже объединяются; конфликтующие версии вложения выбираются отдельно. Пока конфликт не разрешён, сохранение блокируется. Само объединение ничего не записывает на диск. Перед сохранением проверяется, не появилась ли ещё более свежая версия файла. Внешнее изменение во время проверки диффа Work ждёт принятия или отклонения правок агента.

Новый документ отключает прежний watcher. При временном удалении или некорректном `.itex` текст остаётся в памяти, чтение повторяется ограниченное число раз; следующее событие возобновляет обновление. Отслеживается сам документ; отдельные картинки и `.bib` перечитываются при его изменении. Задержка зависит от файловой системы, размера файла и частоты обновления экрана; гарантии 5 мс нет.

Окно AI перемещается за свободную область шапки. Во время ответа кнопка отправки заменяется стопом.

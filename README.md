# Instant TeX

Локальный черновик для математических решений: пиши русским текстом и LaTeX, а результат сразу смотри рядом с кодом. Приложение не запускает полноценный TeX-компилятор: текст и формулы отображаются локально через KaTeX, без установки TeX Live или MiKTeX.

## Скачать

Готовые сборки появляются на странице [Releases](https://github.com/art22017/instant-tex/releases):

- **Windows x64:** portable `.exe`, установка не требуется.
- **Linux x64:** AppImage.
- **macOS x64:** `.dmg` и `.zip`.

Сборки не подписаны сертификатами издателя. Windows или macOS могут показать предупреждение при первом запуске.

## Возможности

- Редактор CodeMirror 6 с автодополнением LaTeX, умным вводом окружений, undo/redo и общим словарём команд.
- Мгновенный предпросмотр русского текста и математических формул на KaTeX, включая `\boxed`, `gather`, `align`, матрицы и другие поддерживаемые KaTeX команды.
- Шаблон нового решения с русской преамбулой и секциями «Задача», «Решение», «Ответ».
- JetBrains Mono для редактора и интерфейса, CMU/Computer Modern для превью. Размеры и вес шрифта редактора настраиваются отдельно; `Ctrl` + колесо меняет масштаб панели под курсором.
- Светлая и тёмная темы.
- Явные команды открыть/сохранить `.tex`/`.txt`; экспорт текущего превью в PDF, PNG или буфер обмена.
- Необязательный AI-чат через OpenRouter с потоковым ответом, историей, Markdown и LaTeX.

Черновик редактируется в памяти. Автосохранения исходника нет: сохрани текст явно, если хочешь оставить его после закрытия. PDF — экспорт предпросмотра Chromium, а не результат pdfLaTeX или XeLaTeX. Полный LaTeX-проект, произвольные пакеты, TikZ, библиография, изображения и макросы из пользовательской преамбулы не компилируются.

## AI и ключ

AI выключен, пока пользователь сам не добавит ключ OpenRouter в настройках AI. Запрос уходит в OpenRouter из основного процесса приложения; текст документа, выделение и вопрос отправляются только при явном запросе AI. Остальные части приложения работают офлайн.

Ключ не хранится в исходниках, GitHub Actions, аргументах сборки или файлах релиза. На Windows он шифруется DPAPI для текущего пользователя в `%APPDATA%/InstantTeX`; на macOS/Linux используется Electron `safeStorage`. В workflow нет секрета OpenRouter и он не нужен для сборки или публикации приложения.

## Разработка

Нужен Node.js 22 или новее.

```sh
npm ci
npm start
npm test
npm run build
```

`npm run dev` запускает только UI в браузере; диалоги сохранения и экспорта доступны в Electron. Windows portable-сборка из локальной среды создаётся командой `npm run package`.

## Релизы

Опубликуй версионный Git-тег вида `v0.6.1`. GitHub Actions проверит версию в `package.json`, выполнит unit-тесты и соберёт приложение на отдельных GitHub-hosted Windows, Ubuntu и macOS runner-ах. Успешный запуск создаст GitHub Release и добавит Windows portable, Linux AppImage, macOS DMG и ZIP. Для сборки не требуются Actions secrets.

Технологии: Electron, CodeMirror 6, KaTeX, JetBrains Mono Variable, Computer Modern, Lucide.
